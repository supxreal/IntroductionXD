"เร่งทดสอบ Siri เวอร์ชันใหม่ ออกแอปแนว ChatGPT ให้พนักงานทดสอบสะดวกมากยิ่งขึ้น"

รายงานนี้มาจาก Mark Gurman แห่ง Bloomberg คนเดิม เขาพูดถึงแผนการพัฒนา Siri ใหม่ที่เป็น LLM ซึ่งแอปเปิลประกาศเลื่อนกำหนดอัปเดตไปก่อนหน้านี้ และกำลังเร่งเปิดตัวเร็วที่สุดเพื่อให้ตามทันคู่แข่ง Gurman บอกว่าตอนนี้ตัว Siri มีความคืบหน้ามาก แต่แอปเปิลต้องการทดสอบให้มากที่สุด จึงได้ออกแอปเฉพาะเพื่อให้สะดวกขึ้นสำหรับพนักงานแอปเปิล

แอปนี้คล้ายกับแอป ChatGPT แต่วิธีการทำงานจะติดต่อไปที่ Siri ใหม่ แอปยังมีระบบให้คะแนนความพึงพอใจกับคำตอบแบบ ChatGPT ด้วยข้อมูลใหม่ที่ Gurman รายงานมีเพียงเท่านี้ โดยก่อนหน้านี้มีข่าวว่า Siri ใหม่ใช้วิธีการพัฒนาไปสองทาง คือหนึ่งใช้โมเดล AI ที่แอปเปิลพัฒนาเอง และสองคือใช้โมเดลจากบริษัทเทคโนโลยีอื่น ซึ่งมีความเป็นไปได้สูงว่าคือกูเกิล

"Windows ML รันไทม์สำหรับรันโมเดล AI"

ไมโครซอฟท์ประกาศข่าว Windows ML รันไทม์สำหรับรันโมเดล AI บนฮาร์ดแวร์ Windows ที่เปิดตัวในงาน Build 2025 เข้าสถานะ generally available (GA) พร้อมใช้งานระดับโปรดักชัน Windows ML เป็นส่วนหนึ่งของ Windows AI Foundry โดยทำหน้าที่เป็นตัวกลางระหว่างโมเดล AI ฟอร์แมต ONNX กับหน่วยประมวลผลหลายรูปแบบ (CPU, GPU, NPU) เพื่อให้ง่ายต่อการรันโมเดลแบบ local ในเครื่องอย่างมีประสิทธิภาพ โดยไมโครซอฟท์ทำหน้าที่คุยกับ AMD, Intel, NVIDIA, Qualcomm ให้เลยสำหรับนักพัฒนาแอพ มีหน้าที่ส่งโมเดลไปรันผ่าน Windows ML อย่างเดียวปัจจุบันมีแอพดังๆ หลายตัว

เช่น Adobe Premiere Pro, Adobe After Effects, McAfee เรียกใช้งานฟีเจอร์ AI ผ่าน Windows ML แล้ว รองรับระบบปฏิบัติการที่เป็น Windows 11 24H2 ขึ้นไป

"ระบบปฏิบัติการในยุคเก่าที่สำคัญ DOS และ UNIX"

ดอส (DOS) หรือ Disk Operating System เป็นระบบปฏิบัติการบนเครื่องพีซี สำหรับเครื่องไอบีเอ็มหรือ ไอบีเอ็มคอมแพ็ททิเบิล (IBM Compatible) ที่นิยมมากในอดีต ถูกพัฒนาขึ้นในปี ค.ศ. 1980
• เป็นระบบปฏิบัติการแบบผู้ใช้งานคนเดียว (Single User) และ 1 CPU (Singleprocessor)
• ทำงานกับ CPU ขนาด 8 บิตและ 16 บิต
• รู้จักหน่วยความจำหลักแค่ 640 KB
• รองรับการตั้งชื่อแฟ้มข้อมูลขนาด 8 ตัวอักษรและส่วนขยาย 3 ตัวอักษร
• ใช้การจัดการหน่วยความจำแบบ Monoprogramming

ยูนิกซ์ (UNIX) เป็นระบบปฏิบัติการที่ถูกพัฒนาขึ้นในปี ค.ศ.1969 โดยบริษัท AT&T เพื่อใช้งานกับมินิคอมพิวเตอร์ โดยแรกเริ่มถูกใช้งานเพื่องานวิจัยเพื่อศึกษาในมหาวิทยาลัยเท่านั้น
• เป็นระบบปฏิบัติการแบบผู้ใช้งานหลายคน (Multi-User)
• สนับสนุนการทำงานหลายงาน (Multitasking)
• เป็นระบบปฏิบัติการที่พัฒนาขึ้นด้วยภาษาซี (C)
• ไม่ยึดติดอยู่กับฮาร์ดแวร์ จึงสามารถนำไปใช้กับคอมพิวเตอร์ได้เกือบทุกแบบ
• มีความสามารถในการเชื่อมต่อกับระบบเครือข่าย
• ติดต่อกับผู้ใช้งานผ่านทาง Command line แต่ในปัจจุบันมีการพัฒนาโปรแกรมเป็นลักษณะของ GUI เพื่อให้ใช้งานได้ง่ายขึ้น
• ปัจจุบันนิยมนำมาใช้เป็นเครื่องให้บริการประเภทต่างๆ เช่น Web Server
