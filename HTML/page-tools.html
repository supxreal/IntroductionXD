Tools & Credit

    • ภาษาที่ใช้เป็นโครงสร้างหลักสำหรับสร้างเว็บไซต์

  • CSS3

  • JavaScript

Visual Studio Code
เครื่องมือหลักที่ใช้ในการพัฒนาเว็บไซต์และแก้ไขโค้ด โดยภาษาที่ใช้หลักๆได้แก่ HTML/CSS/JS และยังติดตั้งส่วนขยายที่ช่วยในการทำเว็บง่ายขึ้นคือ Auto Close Tag, Auto Rename Tag และ Live Server สำหรับพรีวิว
Safari/Chrome DevTools
ใช้ตรวจสอบองค์ประกอบ (Elements) และใช้พรีวิวเว็บไซต์ว่าสามารถ Responsive ได้ขนานไหนแล้วถึงการ Console สำหรับดีบัก
Google Gemini
ช่วยอธิบายโค้ดว่าทำงานอย่างไร, ช่วยแก้บั๊ก, ช่วยออกแบบโครงสร้าง semantic HTML, CSS ให้เว็บไซต์ดีมากขึ้น
